# C4 子集来源收集：给本地 GPT 的提示词

用途：为"外部新颖性与重要性"（测量框架 §3.2，C4）收集题源。现有三个平台（PeerJ、F1000Research、ORE）的审稿都不评价新颖性，所以需要另找来源。把下面整段交给本地 GPT。

---

请帮我收集一批社会科学论文，要求论文的**审稿记录公开**，并且审稿意见中**评价了新颖性或重要性**。

**来源**（先做第 1 个；其余的请先核实它们是否公开审稿记录，再决定要不要做）：
1. Nature Human Behaviour：带有 Peer Review File（透明审稿文件）的原创研究（Article）。
2. Nature Communications 中社会科学和心理学方向、带有 Peer Review File 的论文。
3. 其他你确认会公开审稿记录、而且审稿标准包含新颖性的社会科学期刊。请写明你是依据哪条政策确认的，并附上链接。

**入选条件**：
- 学科属于 OECD 第 5 大类（社会科学），包括心理学、经济学、教育学、社会学、政治学、传播学等。纯神经科学、纯医学不算。
- 审稿记录中至少有一位审稿人对新颖性、贡献或重要性做了**实质性评价**，不能只是一句"有意思"。
- 审稿记录中能看到首轮投稿稿件，或者首轮审稿意见对应的版本信息。
- 发表日期优先选 2025-06-01 以后的。这一条要记录，但不作为硬性排除条件。

**每篇论文请提供**：
- DOI、标题、期刊、发表日期、学科；
- Peer Review File 的 PDF；
- 正式发表版 PDF；如果能找到首轮投稿版（例如预印本），也一并提供；
- 首轮编辑决定（如果文件里有）；
- 每位审稿人关于新颖性和重要性的原文摘录，标注审稿人编号和页码。

**数量**：先收集 15 篇，我们看过质量后再决定是否扩充到 40 篇。

**上传位置**：仓库的 `data/originals/c4_novelty/<期刊>/<DOI 转写为文件名>/` 目录。另附一份 `data/originals/c4_novelty/manifest.csv`，每篇一行，列出上面要求的字段。

**不要做的事**：
- 不要总结或改写审稿意见，摘录必须是原文；
- 不要猜测审稿人的身份；
- 某篇论文找不到首轮版本时，如实写明，不要用发表版冒充首轮投稿版。
