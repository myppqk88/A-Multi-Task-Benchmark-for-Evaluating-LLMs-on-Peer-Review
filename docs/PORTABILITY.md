# 迁移与复现说明

本版从已完成的本地 282 题候选评分参照包迁移，保留原任务、样本划分、实质评分内容和未核验状态。

- JSON/CSV 内的本机路径改为仓库根目录相对路径，评分卡阅读版链接相对自身文件解析。
- 所有 282 份 input.json 保持本地快照字节；题内图像和附件路径仍相对题目目录。
- 路径元数据变化会改变相关文件哈希，已更新来源绑定、评分卡哈希和空模板。`data/export_provenance.json` 同时登记原快照哈希与导出哈希；原始本地文件没有被修改。
- `evaluation/validate_package.py` 已适配仓库根目录路径，检查引文定位、哈希、题号、评分字段与材料边界；没有删除原检查项目。
- 二进制材料按内容 SHA256 去重保存在 Release 分卷。下载器校验分卷及每个对象，然后恢复清单中的每条路径。Git 跟踪文本和恢复清单，不跟踪大体积来源二进制。
- `evaluation/validation_report.json` 是迁移后检查结果；评分工具构造数据测试与真实模型实验严格分开。
- 构建时期的临时脚本、代理日志、私人交接对话以及重建空模板的脚本没有加入常规使用入口，避免误运行覆盖已填写评分。

`data/question_bank/工作记录/` 中只包含溯源实际需要的文本，不是全部会话记录。`evaluation/source_freeze_manifest.json` 描述迁移后的冻结文件；原快照对应可在 export_provenance 查到。校验通过仅表示机械对应关系成立。
