# 最近邻研究核对：不能把科学性评价本身当作已成立创新

本轮对照原论文方法段、作者项目页或作者代码库。没有运行其代码，没有独立复现其结果；以下是定向核对，不是系统综述完成或穷尽性检索。

| 研究与实际核对范围 | 原文已经做了什么 | 对本包的约束与可检验区别 |
|---|---|---|
| [ReviewMT，Tan等，2024](https://arxiv.org/html/2406.05688)，§4.4及任务定义；作者仓库为chengtan9907/ReviewMT | 多角色、多轮评议，包括初评、回应、后续评议及决定。指标包括回复有效性、文本相似度、评分MAE和决定F1。 | 不能声称首次覆盖评议过程。可比较本包是否在三个具体判断场景中提供更充分的证据、推理与结论范围评价。不能据此一篇概括整个领域只看准确率。 |
| [ReviewGrounder中的ReviewBench，Li等，2026](https://arxiv.org/html/2604.14261)，§3.1–3.3、§5人类评价 | 已用论文、聚合真人意见和公共rubric构建逐篇可核查要求，强调原稿证据；八维含证据批评、结果解释及错误主张。正向维度0/1/2，负向维度−2/−1/0，并有专家评分比较。 | **最接近本包“真人意见→逐题评分参照”的方法。**不能将这个转换本身宣称原创。待验证区别在三场景的共同构念、版本证据边界、合理反驳及五级解释；仅把八维改三维、三级改五级不足以证明贡献。 |
| [PRISM，2026](https://arxiv.org/html/2605.26730v1)，§3四条管线及§4新颖性解释 | 已测分析深度、文献支撑的新颖性判断、科学缺陷与优先级、建设性；结合原稿核验，将人类和模型意见形成相对共识参照。原文明确新颖性得分不认证客观领域新颖性。 | 不能声称已有评价不看科学性、不允许模型发现人类未提的问题。需比较本包开放答案与未决争议机制是否带来额外可靠性；PRISM的共识机制本身也不能替本包完成效度验证。 |
| [RPC-Bench，Chen等，ACL 2026](https://aclanthology.org/2026.acl-long.1277/)，作者摘要、[项目方法说明](https://rpc-bench.github.io/)及正式PDF首页 | 从真实评审—回应改写论文理解问答，使用人机协同核验，并评价正确性、完整性、简洁性及主张验证。 | 数据来自评审往返不是本包独有。回答论文问题与判断作者回应是否充分有区别，但仍需实证检验是否超出论文理解/知识能力。网页摘要与PDF首页的样本规模口径不一致，本记录不混用其数量，待核版本/子集关系。 |
| [ReviseBench，Luo等，2026](https://aclanthology.org/2026.findings-acl.887.pdf)，§3.2–3.3及限制 | 让模型依据评审实际修改论文与实验，评价有效产物及相对原稿/人工后稿的成对质量，另用独立JudgeTest检查裁判。 | 本包T3评价修订是否解决问题，不是要求生成修订稿；二者接近但输出任务不同。可借鉴独立裁判校验，不能把人类最终版本或接受结果自动当科学正确性。 |
| [Kahneman4Review，2026](https://arxiv.org/html/2607.10511)，§3及§4.1 | 已尝试理论驱动、多维、有定位片段的认识论质量评分；原文明确无论文访问时只能测文本线索，不能确定批评正确或真实认知过程。也报告九维未经验地区分为九个构念。 | 三维有理论解释不等于经验上可区分。我们需直接对照原稿及修订证据，同时检验维度关联和增量；不能从写出推理链直接推断一般智能。 |

## 同名与来源注意

ReviewBench至少有不同项目使用同名。上表指ReviewGrounder配套基准；[researchbites/reviewbench](https://github.com/researchbites/reviewbench)是另一作者公开项目，README已列主张映射、意见后果、具体性、理由及跨来源重合等指标，也不是单一准确率。它还不同于GitHub代码审查基准review-bench/ReviewBench。本轮只核对researchbites的README，未审其完整方法论文或代码实现，不能合并三者描述。

最初检索出现SmallBlueWolf/ReviewMT仓库，其数据描述不能替代Tan等原论文及作者仓库。OpenReview的RPC-Bench旧PDF链接遇到浏览器验证，随后转用作者项目页和ACL正式记录；没有声称已读被拦截版本。

## 当前可以说到哪里

可以提出：本项目拟将证据约束下的学术判断落实到原稿评审、回应评价、修订综合判断三个场景，并把真人可错、材料不足及修订证据作为评分边界。这个设计已被具体化，但是否优于最近邻、是否提供增量测量证据，仍待独立验证。

不能写：既有benchmark只看准确率；首次评价科学性；首次使用真人意见构建逐篇rubric；三维五级已经测得一般智能；框架创新已经核实。
