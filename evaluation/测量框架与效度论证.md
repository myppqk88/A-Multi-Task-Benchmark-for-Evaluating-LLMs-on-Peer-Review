## 1. 构念：测的是什么，不测什么

**目标构念**：在社会科学同行评议的三个环节中，模型**仅依据给定材料**作出科学判断的能力。这里的科学判断要满足三点：**证据准确**、**推理成立**、**结论与证据相称**。

| 任务 | 子构念 | 模型可见的材料 |
|---|---|---|
| T1 原稿评审 | 识别并论证稿件中最重要的科学问题 | 原稿 v1（文本和页面图像） |
| T2 回应评价 | 判断作者的回应文字是否真正处理了审稿关切 | 一条关切（或一整份报告）及作者回应；不提供修订稿 |
| T3 修订综合判断 | 对照前后两版稿件，判断问题是否真正解决、还遗留什么 | v1、v2，截止时点前的全部报告与回应，以及 Amendments |

**不主张的内容**（论文中必须明确写出）：
- 一般智能，或"科学智能"的总分；
- 创新性与重要性的判断。这类判断没有可以核查的参照答案，题源平台的审稿人也不评价它，最终应由编辑和同行来定。第 3.2 节只做**不计分的观察**；
- 期刊编辑决定的准确性；
- 模型可以替代审稿人；
- 结论推广到社会科学以外的学科。

**基本立场**：真人评议意见是**证据来源和参照点**，不是标准答案。同行评议者之间的一致性本来就很低（Bornmann, Mutz & Daniel, 2010），所以模型的判断与真人不一致，并不等于模型错。判断对错的依据是**原稿材料本身**。

## 2. 理论基础

| 设计要素 | 理论来源 | 在本框架中的作用 |
|---|---|---|
| 三个评分维度 | Toulmin（1958）的论证模型：主张、依据、推理保证、限定、反驳 | 证据准确性对应**依据**；论证成立性对应**推理保证**及对反驳的处理；结论适当性对应**限定**，即结论强度与适用范围 |
| 问题类型分类（第 3 节） | Shadish, Cook & Campbell（2002）的四类效度；Lincoln & Guba（1985）的质性研究可信度标准；APA 报告规范 JARS-Quant 与 JARS-Qual（Appelbaum 等, 2018；Levitt 等, 2018）；混合方法评估工具 MMAT（Hong 等, 2018） | 界定社会科学研究中"科学问题"的**内容域**，用来检验题库的覆盖面，并给每条判断标注类型 |
| 真人意见只作参照 | 同行评议一致性研究（Bornmann 等, 2010）；评审质量评估工具（van Rooyen, Black & Godlee, 1999） | 不把真人意见当金标准；允许有依据的反驳和新发现 |
| 开放回答的评分 | 表现性评价与量表评分；多面 Rasch 测量（Linacre, 1989） | 用有锚点的量表、受训评分者、可以建模的评分者宽严差异来给自然语言回答打分 |
| 把长回答拆成论点逐条核查 | 原子事实分解与核查（Min 等, 2023, FActScore） | L1 论点层：把回答拆成可以逐条判定的单元 |
| 已知缺陷检出 | 在稿件中植入错误、测试审稿人检出率的研究（Godlee, Gale & Martyn, 1998；Schroter 等, 2008） | 植入错误子集（第 6 节）提供有确定答案的效标 |
| 效度的论证方式 | Messick（1995）的统一效度观；Kane（2013）的基于论证的效度验证；AERA/APA/NCME（2014） | 效度不是题库本身的属性，而是"由分数得出某个结论"的合理程度。第 7 节逐环列出证据 |
| 信度与概化 | 概化理论（Brennan, 2001）；加权 κ 与 ICC 的解释惯例（Landis & Koch, 1977；Koo & Li, 2016） | 分解误差来源，并用数据决定需要多少篇论文 |

## 3. 问题类型分类

参照点和模型提出的每一条判断，都要标注**一个主类型**。

| 代码 | 类型 | 典型例子 |
|---|---|---|
| V1 | 构念与测量效度 | 操作化与概念不对应；量表的信度、效度证据不足；编码方案不清 |
| V2 | 内部效度与因果推断 | 设计不能支撑因果结论；混杂；选择偏差；把相关当成因果 |
| V3 | 统计结论效度 | 分析方法不恰当；数字前后矛盾；自由度或检验统计量对不上；多重比较；检验力不足 |
| V4 | 外部效度与推广 | 抽样方式或样本构成不能支撑推广范围 |
| V5 | 质性研究可信度 | 可信性、可迁移性、可依赖性、可确认性不足；资料饱和；研究者反身性 |
| V6 | 理论与论证 | 理论框架与研究问题脱节；论证链条断裂；对文献的使用失当 |
| V7 | 报告透明与可复现 | 方法报告缺项；数据与材料的可得性；伦理程序 |
| V8 | 结论与证据相称 | 过度推论；解释超出数据；局限性讨论缺失 |
| V9 | 非实质性问题 | 语言、格式、引用体例。不计入实质问题的召回率 |

### 3.2 创新性：只观察，不计分（v0.4）

**定位**：本 benchmark 测的是**严谨性判断**，即科学智能能否发现稿件在证据、推理和结论上的问题。创新性不计分，理由有三：
1. **没有参照答案**。三个题源平台审稿时都不以新颖性为标准：PeerJ 的编辑标准是只判断科学是否可靠，不看影响力、进展程度或新颖性；F1000Research 要求审稿人不考虑新颖性；Open Research Europe 与 F1000Research 是同一个平台，它的政策需要再单独核实。因此，真人审稿意见在这一点上提供不了参照。
2. **构念一致**。题源平台的审稿本来就以严谨性为准，本 benchmark 测的也是严谨性。如果另外宣称测创新性，就与数据来源不一致了。
3. **评价权**。创新性和重要性应由编辑和领域同行判断。本研究不主张 AI 应当承担这项判断。

**观察什么**：作答指令中不提创新，也不禁止谈创新；T1 的 `summary` 和 `overall_assessment` 是自由文本，模型在其中主动作出的创新或贡献评价，作为**探索性现象**来分析：

| 编码项 | 取值 |
|---|---|
| 是否主动提及 | 是 / 否 |
| 方向 | 肯定 / 否定 / 中性描述 |
| 依据 | 引用了稿件内的证据 / 依赖稿件之外的领域知识 / 没有给出依据 |
| 是否有效 | 有依据且与稿件内容相符 / 与稿件内容不符，例如称"首次"而稿件自己引用了先例 / 无法判断 |

**报告方式**：只报告描述性频数和典型例子，不计分，不参与模型排名。对照基线是真人审稿人：预实验 27 份审稿报告中有 7 份提到创新，全部是一句带过的肯定。值得关注的问题是：模型是否也倾向于给出没有依据的客套肯定，这与模型迎合用户的倾向有关；以及它的肯定与它自己指出的严谨性问题是否自相矛盾，例如一边列出严重的效度问题，一边称"贡献重要"。编码由一人完成，另抽 20% 由第二人独立编码，并报告一致性。

**与 V 类问题的关系**：稿件**自己的**贡献表述若有可以核查的问题，仍属于严谨性问题，照常计分。例如，称"首次研究"而自己引用的文献中已有先例，属于 V6；贡献表述超出设计所能支撑的程度，属于 V8。

### 3.3 类型分类的用途

**用途**：报告各类型的覆盖分布，证明题库没有集中在少数几类；按类型报告模型的召回率，找出模型的系统性盲区。至少 10% 的论点由两人独立标注类型，κ 应不低于 0.60，否则修订类型定义。

## 4. 三层评分：如何把自然语言回答量化

**基本原则**：不直接给文本"打一个数"，而是把回答拆成可以判定的单元，在三个层次上分别判定。三层结果分别报告，**不合成总分**。

### 4.1 L0 可验证层（程序自动判定）

| 指标 | 定义 |
|---|---|
| 引文可验证率 | 回答中的 `exact_quote`，经过统一的空白和标点规范化后，能在模型可见材料中逐字找到的比例。找不到的记为**虚构引文** |
| 格式合规 | 输出符合 JSON 模式；结论标签属于允许的取值 |
| 信息越界 | T1 提到后续版本的内容；T2 声称修改已经得到验证，即 `revision_verification` 不等于 `not_assessed`；T3 使用了截止时点之后的材料。对应 `公共五级评分规则.json` 中的 S2 |

L0 完全确定，不需要评分者，可以报告到每一题。

### 4.2 L1 论点层（人工裁决，或经过验证的 LLM 裁判）

**拆分单元**：
- T1、T3：`issues` 数组中的每一项为一个论点；
- T2：`addressed_requirements` 和 `remaining_gaps` 中的每一项，再加上总体结论标签。

**每个论点的裁决步骤**：
1. **匹配**：是否对应参照卡上某个**已核实**的参照点，即人工核验后状态为 `supported` 的点。记录对应的参照点 ID。
2. 如果对应参照卡的**中性点**（第 6.3 节），按 `valid_minor` 处理，不进入实质论点的统计，既不加分也不扣分。
3. **其余未匹配的论点**，判为以下四类之一：
   - `valid_new`：有材料依据、推理成立的实质性新问题；
   - `valid_minor`：成立，但属于非实质问题；
   - `invalid`：事实错误、误读材料，或者推理不成立；
   - `unverifiable`：凭现有材料无法裁决。这类论点送争议流程，不计入精确率的分母。
4. 标注问题类型，即 V1–V9。

**指标**：

| 指标 | 公式 | 适用任务 |
|---|---|---|
| 重要问题召回率 | 命中的、重要性为 high 的已核实参照点数 ÷ min(题目允许的问题数, 该题 high 参照点数) | T1、T3 |
| 实质论点精确率 | (命中的参照点数 + `valid_new`) ÷ (全部实质论点数 − `unverifiable`) | T1、T2、T3 |
| 错误批评率 | `invalid` ÷ 全部实质论点数 | T1、T2、T3 |
| 结论标签正确率 | 模型给出的标签属于裁决后的**可接受标签集合**即算正确 | T2、T3 |
| 结论标签一致性 | 与裁决后的主判断之间的加权 κ（有序标签） | T2、T3 |

召回率的分母设了上限，是因为题目只允许列最多五个问题。不能因为参照卡上的候选点更多，就要求模型全部列出。

### 4.3 L2 整体层（三维五级量表）

沿用 `公共五级评分规则.json`：证据准确性、论证成立性、结论适当性，各 0–4 分，加上严重错误规则 S1–S3。L2 用来捕捉 L1 拆不开的整体判断质量，例如问题的优先级是否排得合理，各项判断之间是否自相矛盾。

### 4.4 主要终点与次要终点

| 类别 | 指标 |
|---|---|
| **主要终点** | T1、T3 的重要问题召回率、实质论点精确率；T2、T3 的结论标签正确率；所有任务的虚构引文率 |
| **共同主要终点**（有条件） | L2 三个维度。前提是第 7 节"评分"一环的信度标准达标；不达标的话，降为探索性指标并如实报告 |
| **次要终点** | 错误批评率、各问题类型的召回率、多模态消融的差值、发表时间早晚两层之间的差异 |

把 L1 列为主要终点，是因为它的判定单元小、标准清楚，预期信度比整体评分高，结果也更好解释。这一预期本身要由预实验检验。

## 5. 输出格式修订

**T1 改为结构化输出**。原来是一段不超过 1,200 词的自由报告，很难拆分成论点。新格式草案如下：

```json
{
  "summary": "≤150词，稿件的核心主张与总体评价",
  "issues": [
    {
      "claim": "问题陈述",
      "issue_type": "V1|V2|...|V9",
      "status": "confirmed_error|missing_information|suggestion",
      "severity": "major|minor",
      "evidence": [{"input_field": "manuscript_text|page_images", "exact_quote": "...", "location_hint": "节/页/表"}],
      "reasoning": "为什么这是问题、影响哪个结论"
    }
  ],
  "overall_assessment": "≤150词"
}
```

`issues` 最多 5 项。**T2、T3** 保留现有的输出格式，只在 `issues` 中增加 `issue_type` 字段。

**改格式的代价**：已有 63 道 T1 题的 `input.json` 必须重新生成，哈希会随之变化。因此题库要升级到 candidate-v0.2，旧版本保留，以便溯源。

## 6. 参照答案与植入错误子集

### 6.1 参照卡的构建与核验

1. **证据锚定**：每个参照点必须同时引用**真人评议原文**和**原稿中能支撑它的位置**。只在原稿中找到依据、真人没有提出的问题，标为 `source: card_author`，与真人来源的参照点分开统计。
2. **起草方案（待团队决定）**：
   - A. 由一个模型起草；
   - B. 由不参加测试的模型起草；
   - **C（推荐）**：由两个不同家族的模型分别起草，分歧由人工裁决。

   无论选哪种，都要记录每张卡的起草模型。
3. **人工核验**：每张卡至少由一名团队成员逐项核验，内容包括引文、重要性、问题类型、可接受的不同判断和结论标签，每项给出"保留 / 修改 / 删除 / 新增"。另抽 20% 的卡由第二人独立核验，用来估计核验本身的一致性。
4. **改动率**：报告每张卡的改动比例和改动类型，以此作为参照质量的证据。另外预先登记一项**偏差检验**：只在改动率不低于 30% 的卡上，比较与起草模型同家族的被测模型和其他模型的成绩差距，看差距是否缩小。

### 6.2 植入错误子集

**目的**：提供**有确定答案**的效标，检验 L1 的召回率能否真实反映"发现问题"的能力。

| 项目 | 设计 |
|---|---|
| 来源论文 | 从**扩展集**中选取，不与主分析集重叠 |
| 植入方式 | 每份稿件只植入 1 处错误，类型覆盖 V1–V8，例如表中数字与正文矛盾、把相关写成因果、样本描述与推广范围不符。T3 的植入方式是：作者回应声称已经修改，但在 v2 中删去对应的改动 |
| 规模 | 预实验 10 题；正式实验 40 题（检出率的 95% 置信区间半宽约 ±15 个百分点） |
| 判定 | 模型提出的论点中，只要有一条指出了植入的错误，即算检出 |
| 对照 | 同一篇论文的原始版本也要作答，用来区分"真正发现了错误"和"本来就倾向于报告这类问题" |
| 限制 | 植入的错误是人为的，问题情境与真实稿件不同，所以只作为补充效标。改动后的稿件明确标注为研究材料，不作为真实论文对外发布 |

### 6.3 参照卡定稿规则（v0.3 新增，用于预实验第一轮裁决）

裁决员对每一行只选"X对 / Y对 / 都对 / 都不对"。定稿由 `scripts/finalize_pilot_cards.py` 按以下规则机械完成，结果存放在 `evaluation/cards_pilot/`：

1. **两份草稿都有的点**：选了一方，就保留这一方的表述。选"都对"，保留点数较少的一方，因为粒度较粗，符合"一个参照点对应一个独立问题"的规则；点数相同时保留 X，X 是随机分配的，与起草者无关。另一方的表述并入"可接受的不同表述"，双方的引文证据合并。
2. **只有一方提出的点**：被采纳就保留。选了"都不对"，就放进**中性集**：模型提到不加分，也不算无效批评。原因是裁决员反馈，"都不对"既可能表示"不成立"，也可能表示"成立但没必要"，现有数据无法区分，而两种情况都不应该计入召回率。这条规则同时回应了"参照卡吹毛求疵"的问题：被裁决员否掉的细节不会变成模型必须答出的内容。
3. **结论标签**：选了一方，就采用这一方的标签。选"都对"，可接受集合取双方的并集，主判断取双方都接受的标签，有两个时取更严格的一个。
4. **重复点**：分组时没能对齐、内容相同的点，人工确认后合并，名单写在脚本的 `DUPLICATES` 中。
5. **统计类指控**：凡是由起草者发现、涉及数值的指控，由 `scripts/recompute_stat_claims.py` 根据稿件报告的数值复算，并核对引文确实出现在模型可见的材料中。复算结果存放在 `cards_pilot/stat_recompute.json`。这样，裁决员只需要判断这个错误重不重要，不必判断算术对不对。
6. 第二裁决的 8 题，在卡中标为 `provisional_pending_second_adjudication`，等第二裁决完成、双方分歧解决后才算定稿。

**第一轮裁决的概况**：共 273 行，其中 142 行是两份草稿都有的点，这些点没有一行被判为"都不对"；只有一方提出的点共 106 行，其中 36 行被判"都不对"。两位起草者各自被采纳的比例要等第二裁决完成后再揭盲公开。定稿后共有 271 个参照点，其中计入召回率分母的高重要性点 78 个，另有中性点 36 个。D05 的 T1 和 T3 两题没有高重要性的点，所以召回率在这两题上没有定义，只报告精确率。

## 7. 效度论证：逐环证据与事先登记的成功标准

| 推论环节 | 要回答的问题 | 证据与方法 | 成功标准（建议值） | 不达标时的处理 |
|---|---|---|---|---|
| **评分** | 不同评分者的判定一致吗？ | 两人独立评分，回答样本按论文抽取 | L1 有效/无效判定 κ ≥ 0.70；参照点匹配一致率 ≥ 80%；L2 各维度二次加权 κ ≥ 0.60，相差不超过一档的比例 ≥ 90% | 修订裁决规则后，用**新的**样本重新检验；L2 不达标时降为探索性指标 |
| | 评分者的宽严差异有多大？ | 多面 Rasch 模型，估计评分者宽严参数 | 单个评分者的严格度偏离均值不超过 0.5 logit | 重新培训该评分者，或在分析中做校正 |
| | LLM 裁判能替代人工评分吗？ | 与人工评分的一致性；裁判模型对自家模型的偏好检验 | 裁判与人工的 κ 不低于人工之间 κ 减 0.10；对自家模型回答的平均偏差没有显著差异 | 只用人工评分；或者改用多个裁判交叉评分 |
| **概化** | 分数能推广到其他论文吗？ | 概化理论研究：模型 × 论文 × 任务 × 评分者；决策研究推算所需论文数 | 用于模型**相对排名**的概化系数 Eρ² ≥ 0.80 | 扩充论文数量（启用扩展集），或者只报告置信区间不重叠的模型差异 |
| | 模型自身的输出稳定吗？ | 每个模型对每题生成 3 次 | 三次之间按论文计算的排名相关 ≥ 0.80；报告各题内部的方差 | 把多次生成的平均值作为模型得分 |
| **外推** | 召回率真的反映发现问题的能力吗？ | 植入错误子集的检出率与 L1 召回率的相关 | 两者正相关，且 95% 置信区间不包含 0 | 重新审视参照卡的完整性和拆分规则 |
| | 分数能区分科学质量的高低吗？ | 成对对照答案：同一结论配错误理由、正确引文配错误推断、只润色不改内容、有依据地反驳真人、材料不足但正确限定判断 | ≥ 90% 的成对答案中，分数变化方向与事先登记的预期一致 | 修订量表锚点或裁决规则 |
| | （可选）专家能拿高分吗？ | 已知组比较：资深研究者、研究生和模型作答同一批题，盲评 | 资深研究者的平均分高于研究生 | 检查量表奖励的是否真的是专长 |
| **区分** | 分数是不是在奖励字数和文风？ | 在控制 L1 有效论点数之后，看分数与回答长度的偏相关；同一内容改写措辞后的分数变化 | 偏相关的绝对值 < 0.20；改写前后分差的平均值不超过 0.25 档 | 在规则中明确规定不按长度给分，然后重新培训评分者 |
| | 分数是不是在奖励服从？ | 在对照答案中加入"服从审稿人"或"服从作者"的表述 | 服从型答案的结论适当性得分下降 | 修订 S3 规则 |
| **结构** | 三个维度真的是三种能力吗？ | 维度间相关；按论文聚类的验证性因素分析 | 维度间相关 < 0.90 | 改为报告一个合成维度，不再宣称三个维度可以区分 |
| **结论** | 模型排名可靠吗？ | 按论文做自助法，计算两两差值的置信区间，用 Holm 法校正多重比较 | 只有在校正后置信区间不包含 0 时，才宣称两个模型存在差异 | 把排名报告为"并列"或"不可区分" |

## 8. 偏差与污染控制

| 风险 | 控制措施 |
|---|---|
| 参照卡起草模型与被测模型同家族 | 第 6.1 节的起草方案、起草模型记录和改动率偏差检验 |
| LLM 裁判的位置偏好、长度偏好、自我偏好（Zheng 等, 2023） | 裁判看不到回答来自哪个模型；成对比较时随机交换顺序；做长度回归检验；自家模型偏差检验 |
| 训练数据污染 | 以 v1 公开日期 2025-06-01 为界分层报告；各模型训练截止日期以官方公布为准，不能确认的标为"未知"。如果较早的一层成绩显著更高，同时又不能用题目难度解释，就要报告可能存在污染 |
| 上下文长度不同 | 所有模型使用统一的输入上限；超出某个模型上限的题目，从该模型的比较中排除并报告 |
| 读图能力不同 | 纯文本与图文两个条件分别报告，不混在一起评分 |

## 9. 预实验方案（正式实验之前）

- **样本**：校准池中的 12 篇论文。6 篇用于规则校准，另 6 篇用于盲法检验。另加植入错误题 10 道。
- **模型**：1–2 个被测模型。校准池不进入主分析集，所以这里的输出不会污染正式结果。
- **评分**：两名评分者独立完成 L1 和 L2 评分。L0 由程序计算。
- **产出**：
  - 第 7 节"评分"一环各项指标的初步估计；
  - 一个小规模概化理论研究，用来估计正式实验需要多少篇论文；
  - 每张卡和每份回答的平均评分时长，用来估计正式实验的人力；
  - 裁决规则修订记录。
- **门槛**：如果预实验中 L1 的 κ 低于 0.60，先修订规则，再用新样本重复预实验，然后才能进入批量成题。

## 10. 结果报告规范

- 按任务和材料单位（T2 单关切、T2 整份报告）**分别报告**，不合成跨任务的总分。
- 汇总方式：同一篇论文内的多道题先取平均，再按论文等权平均；置信区间按论文聚类计算。
- 必须报告的信息：纳入和排除的题目数及原因；`pending` 和 `unverifiable` 的数量；各模型的版本号、调用日期和参数；多模态条件；污染分层结果；所有未达到成功标准的检验。
- 不得报告：把 `pending` 当作 0 分；用一个 κ 值概括全部的信度和效度；只报告对自己有利的那一层结果。
