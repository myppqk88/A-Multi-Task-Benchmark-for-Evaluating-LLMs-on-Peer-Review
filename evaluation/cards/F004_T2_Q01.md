## 三维五级评分

依据完整回答评分；参照点不是命中清单。以下公共档位与逐题边界共同使用。

按原题字数与最多关切数量评价重要性选择。T1/T3要求最多五项重要问题，卡片有更多候选不意味着必须全列；合理合并或优先处理关键问题仍可高分。只有遗漏会改变主要判断的重要证据才影响档位，并须写明影响，不能以篇幅、条数或命中率替代科学性。

### 证据准确性

准确区分评审要求与回复中的实际陈述：回复逐七点作答，将QH改定位为工具，说明与预注册技术演化关系、增案例、承认预期来源边界仍开放，并有理由保持百科短文的理论范围。

| 分值 | 公共档位含义 |
|---|---|
| 0 | 核心证据捏造、对象/版本颠倒或与题内材料直接矛盾，导致主要判断失效。 确认有效作答尝试但无实质回答时该维记0，并标记nonresponse。运行失败或材料不足本身不按0处理；有依据地限定判断仍可高分。 |
| 1 | 引用零散或错配，主要判断缺少可定位支持；把作者声称当已核事实。 |
| 2 | 部分关键事实准确，但漏掉改变判断的重要限定或证据，仍可辨认有效部分。 |
| 3 | 主要事实与角色、版本、范围准确，可定位证据支持关键判断；仅有不改变结论的遗漏。 |
| 4 | 关键事实及限制均准确并相互核对，区分明示、推断与未知；无实质性证据错误。 |

**本题2→3分边界：** 由部分概括提升为准确覆盖：整报告需比较QH与辅助假设、位置性；解释预先记录价值、具体例子、隐性预期与文献/试点边界、集体位置性以及概念/隐喻身份。

**本题3→4分边界：** 全部影响结论的事实与引用一致，且没有把材料不可见夸为作者未做。

高分条件：

- 完整准确复述以下要求：整报告需比较QH与辅助假设、位置性；解释预先记录价值、具体例子、隐性预期与文献/试点边界、集体位置性以及概念/隐喻身份。
- 引文与作者实际回应相符，承诺、报告数值和解释理由不相互替换。

低分风险：

- 把作者未给出的步骤/结果写成已经给出；或漏读完整回复的对应内容。

- **0**：无可评估的证据判断，或虚构题内关键文字。
- **1**：仅泛称作者接受或拒绝建议，未准确辨识本题实际答复。
- **2**：提取部分真实内容，但漏掉或误述影响判断的一项要求：整报告需比较QH与辅助假设、位置性；解释预先记录价值、具体例子、隐性预期与文献/试点边界、集体位置性以及概念/隐喻身份。
- **3**：准确概括要求与回复，能识别：回复逐七点作答，将QH改定位为工具，说明与预注册技术演化关系、增案例、承认预期来源边界仍开放，并有理由保持百科短文的理论范围。
- **4**：重要要求与回复均有逐字可核证据支持，准确标明信息缺失所在；不把未引述的后稿内容当可见事实。

### 论证成立性

判断回复如何满足或未满足科学要求：对QH比辅助假设/位置性多做什么主要仅称已加，未给具体区分；预先记录价值和案例内容未展示，集体位置性的否定理由仍需与原关切对齐。

| 分值 | 公共档位含义 |
|---|---|
| 0 | 主要推论无效或依赖错误科学前提，无法支撑判断。 确认有效作答尝试但无实质回答时该维记0，并标记nonresponse。运行失败或材料不足本身不按0处理；有依据地限定判断仍可高分。 |
| 1 | 主要靠断言、权威/平台状态或服从评审；未建立证据到判断的关系。 |
| 2 | 至少一条实质推理成立，但关键链条/替代解释/关切子项有明显缺口。 |
| 3 | 关键推理成立，解释证据如何支持判断并处理主要反证/限制；有次要遗漏。 |
| 4 | 核心关切的推理完整且可审查，恰当权衡替代解释、反驳和可行条件；不要求额外新奇观点。 |

### 结论适当性

在T2文字任务中选择与上述证据和理由相称的充分性结论；候选为partially_sufficient

| 分值 | 公共档位含义 |
|---|---|
| 0 | 总判断与已核关键证据相反或严重越过任务可知范围。 确认有效作答尝试但无实质回答时该维记0，并标记nonresponse。运行失败或材料不足本身不按0处理；有依据地限定判断仍可高分。 |
| 1 | 结论过度确定/泛化，忽略决定性缺口，或用拒绝作答回避可判断部分。 |
| 2 | 方向部分合理，但严重性、覆盖或不确定性把握不足；不能据此作稳健总体判断。 |
| 3 | 结论与重要证据相称，明确剩余缺口和任务边界；轻微程度判断差异可接受。 |
| 4 | 结论强度、适用范围、重要性及未知均与材料匹配；合理反驳/材料不足/新有效意见同样可获满分。 |

**本题2→3分边界：** 充分性判断不得越界为修订核验；须对应：对QH比辅助假设/位置性多做什么主要仅称已加，未给具体区分；预先记录价值和案例内容未展示，集体位置性的否定理由仍需与原关切对齐。

**本题3→4分边界：** 标签与理由、未知的处理一致；同一任务定义下有理由的不同标签可同得4。

高分条件：

- 结论承认已答部分，也保留与本关切直接相关的缺口。
- revision_verification=not_assessed；没有后稿不自动降低文字充分性。

低分风险：

- 宣称实际修改已核实；或因看不到后稿就全盘否定有内容的答复。

本题档位示例（与公共规则共同解释）：

- **0**：未给可评估结论，或决定性地把本题变成已核实实际修改/论文真伪的判断。
- **1**：有可评估判断但出现严重局部越界，如声称某处实际修改已经核实；或标签与核心理由明显相反。
- **2**：结论大致相关，但未区分文字是否充分与科学主张是否已证实。
- **3**：结论与本题已答和未答要素相称，并明确not_assessed。
- **4**：结论精确限于本题文字证据；对影响标签的具体缺口交代其权重，不把未验证后稿或需更多材料本身当作者答复失败。

## 严重错误与开放答案边界

- 不得用原稿、后稿或后来评审替本题作者补答。
- 不得把真人关切自动当作正确前提。
- 不得遗漏本题要求：整报告需比较QH与辅助假设、位置性；解释预先记录价值、具体例子、隐性预期与文献/试点边界、集体位置性以及概念/隐喻身份。
