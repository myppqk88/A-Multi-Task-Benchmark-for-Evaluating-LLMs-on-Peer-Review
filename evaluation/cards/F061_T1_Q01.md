## 关键判断与允许的不同答案

### P1 · supported · 候选参照

重点/非重点用途已经解释为数量+深入质性与仅数量，拍卖资格池和选中五国重合合理；更有效要求是交代地理平衡如何具体操作及重点国选择的其他差异因素，而非声称集合逻辑矛盾。

证据：E1。重要性：high。修复可理解性须建立在正确读原稿上。

允许的不同判断：

- 可以接受现有目的性选择而不要求概率抽样，提出更多标准仅为透明性提升。

### P2 · supported · 候选参照

金融输入混含项目数据、国家估计、区间和记忆回答，且按国家/技术汇总；应明确单位、项目规模与受访者角色含义，避免把所有值视为可交换的独立项目观察或机构官方立场。others仅举顾问，可补类别边界。

证据：E1, E3, E4。重要性：high。数据可比性与统计单位决定后续跨国分析是否有效。

允许的不同判断：

- 数据札记可以保留异质资料，但要清晰给使用限制；不必在本文完成回归调整。

### P3 · supported · 候选参照

已有给受访者发聚合图、收反馈的外部环节及两次内部研讨，因此不能说只有内部验证。工作坊未系统记录、量化值未改变，作用是解释与合理性检查，不能等同独立核实或可重复的假设检验。

证据：E2。重要性：high。验证方法的证据层级影响数据可信度而非是否叫validation。

允许的不同判断：

- 可以肯定保密条件下的成员反馈与内部核查，建议明确参与者/反馈处理及审计限制。

### P4 · supported · 候选参照

少于3输入的国家技术组被排除以保护保密，240变206的规则明确；这种保护不保证全数据匿名绝对安全，也不自动提高代表性。原稿承认未公开访谈，不能指控无披露；需把保密、可审计和样本选择风险区分。

证据：E3, E2。重要性：high。数据开放与隐私保护有正当边界，排除规则可能改变覆盖。

允许的不同判断：

- 允许受限访问/聚合公开；可建议报告缺失与剔除对范围影响，而不要求泄露访谈。

## 三维五级评分

依据完整回答评分；参照点不是命中清单。以下公共档位与逐题边界共同使用。

按原题字数与最多关切数量评价重要性选择。T1/T3要求最多五项重要问题，卡片有更多候选不意味着必须全列；合理合并或优先处理关键问题仍可高分。只有遗漏会改变主要判断的重要证据才影响档位，并须写明影响，不能以篇幅、条数或命中率替代科学性。

### 证据准确性

正确读取选择池、数据单位、外部反馈与保密规则。

| 分值 | 公共档位含义 |
|---|---|
| 0 | 核心证据捏造、对象/版本颠倒或与题内材料直接矛盾，导致主要判断失效。 确认有效作答尝试但无实质回答时该维记0，并标记nonresponse。运行失败或材料不足本身不按0处理；有依据地限定判断仍可高分。 |
| 1 | 引用零散或错配，主要判断缺少可定位支持；把作者声称当已核事实。 |
| 2 | 部分关键事实准确，但漏掉改变判断的重要限定或证据，仍可辨认有效部分。 |
| 3 | 主要事实与角色、版本、范围准确，可定位证据支持关键判断；仅有不改变结论的遗漏。 |
| 4 | 关键事实及限制均准确并相互核对，区分明示、推断与未知；无实质性证据错误。 |

**本题2→3分边界：** 须识别原稿已有外部验证与重点国用途。

**本题3→4分边界：** 所有核心批评有前稿支持，不编造无数据共享或无伦理说明。

高分条件：

- 不复述真人误读，引用前稿已有两模板/外部反馈/240→206。
- 准确定位真实缺口，区分项目、国家估计、区间和输入人数，不用后稿补事实。

低分风险：

- 声称原稿未解释重点国
- 说只有内部验证

### 结论适当性

数据札记的使用价值及描述性边界。

| 分值 | 公共档位含义 |
|---|---|
| 0 | 总判断与已核关键证据相反或严重越过任务可知范围。 确认有效作答尝试但无实质回答时该维记0，并标记nonresponse。运行失败或材料不足本身不按0处理；有依据地限定判断仍可高分。 |
| 1 | 结论过度确定/泛化，忽略决定性缺口，或用拒绝作答回避可判断部分。 |
| 2 | 方向部分合理，但严重性、覆盖或不确定性把握不足；不能据此作稳健总体判断。 |
| 3 | 结论与重要证据相称，明确剩余缺口和任务边界；轻微程度判断差异可接受。 |
| 4 | 结论强度、适用范围、重要性及未知均与材料匹配；合理反驳/材料不足/新有效意见同样可获满分。 |

## 核验范围

- **read**：- 完整读两份当轮评审和对应回复作私有线索；定点读原稿摘要、取样/模板、数据处理、保密、分类与验证段。
- **not_read**：- 未目视本题原稿全部图；未访问数据集或保密访谈；未全文逐字读。
- **verification_limits**：- 不判断各财务数值正确性，不把后稿容量/个人观点脚注当原稿事实。
