## 关键判断与允许的不同答案

### P1 · supported · 候选参照

“幻觉不再主要担忧”过强且与结论仍要求专业核查形成张力。应区分缓解技术发展、具体采样回答的正确性和所有专业部署的风险；本研究设计不能证明普遍幻觉问题已解决。

证据：E1, E4。重要性：high。直接影响P/CVE专业应用的可信度边界。

允许的不同判断：

- 可以肯定作者其他段落已提醒专业核查，但这不能完全抵消该绝对化表述。

### P2 · supported · 候选参照

已给三项评估标准和分析问题，仍应交代谁作具体判断、独立/共同流程、如何处理分歧及把回答判为准确/实用的来源依据；作者领域经验并不自动等于可靠评估程序。

证据：E2, E3。重要性：high。研究主要证据来自研究者对50回答的质性判断，程序透明是可审查性的核心。

允许的不同判断：

- 不强制量化信度或盲评；可接受解释清楚的共同反思/共识分析，建议与探索性mapping范围相称。

### P3 · supported · 候选参照

前稿已说明Copilot选择理由、免费未登录、2025年1月采集、单次运行及两组数据集，因此不能说完全无版本背景/无数据/无局限。仍可要求服务配置、会话状态及逐条判断记录，以区分运行复现与资料可审计。

证据：E2, E3, E4。重要性：high。事实准确与复现范围需要同时顾及。

允许的不同判断：

- 动态服务没有公开不可变版本时可用日期与保存对话；日期不保证唯一模型也不保证再次输出相同。

### P4 · supported · 候选参照

专家模拟的50提示可支持探索性内容观察，不能直接证明真实从业者获益、恐惧减少或评价文化改变。结论的陪伴/导师及优点胜过缺点应按本次数据边界表述，并与真实用户研究、重复运行验证区分。

证据：E2, E3, E4。重要性：high。有效内容与实际行为效果是不同构念；题内已承认未纳真实从业者。

允许的不同判断：

- 允许提潜在教育用途及后续研究价值，不要求当前文章完成全套实地效果试验。

## 三维五级评分

依据完整回答评分；参照点不是命中清单。以下公共档位与逐题边界共同使用。

按原题字数与最多关切数量评价重要性选择。T1/T3要求最多五项重要问题，卡片有更多候选不意味着必须全列；合理合并或优先处理关键问题仍可高分。只有遗漏会改变主要判断的重要证据才影响档位，并须写明影响，不能以篇幅、条数或命中率替代科学性。

### 证据准确性

已有方法/数据/局限与真实缺口准确区分。

| 分值 | 公共档位含义 |
|---|---|
| 0 | 核心证据捏造、对象/版本颠倒或与题内材料直接矛盾，导致主要判断失效。 确认有效作答尝试但无实质回答时该维记0，并标记nonresponse。运行失败或材料不足本身不按0处理；有依据地限定判断仍可高分。 |
| 1 | 引用零散或错配，主要判断缺少可定位支持；把作者声称当已核事实。 |
| 2 | 部分关键事实准确，但漏掉改变判断的重要限定或证据，仍可辨认有效部分。 |
| 3 | 主要事实与角色、版本、范围准确，可定位证据支持关键判断；仅有不改变结论的遗漏。 |
| 4 | 关键事实及限制均准确并相互核对，区分明示、推断与未知；无实质性证据错误。 |

**本题2→3分边界：** 须承认前稿已有选择理由、局限和数据声明。

**本题3→4分边界：** 重大意见都有原稿定位，不用后稿内容补事实。

高分条件：

- 准确引用幻觉断言和既有单次运行/日期/数据库声明。
- 不重复真人关于全无局限/数据的隐含前提，不把未访问数据库当未开放。

低分风险：

- 声称原稿无任何局限
- 声称所有模型幻觉已解决

### 论证成立性

三标准质性判断流程与效用外推之间的逻辑。

| 分值 | 公共档位含义 |
|---|---|
| 0 | 主要推论无效或依赖错误科学前提，无法支撑判断。 确认有效作答尝试但无实质回答时该维记0，并标记nonresponse。运行失败或材料不足本身不按0处理；有依据地限定判断仍可高分。 |
| 1 | 主要靠断言、权威/平台状态或服从评审；未建立证据到判断的关系。 |
| 2 | 至少一条实质推理成立，但关键链条/替代解释/关切子项有明显缺口。 |
| 3 | 关键推理成立，解释证据如何支持判断并处理主要反证/限制；有次要遗漏。 |

### 结论适当性

探索性内容映射价值与未证实真实使用效果。

| 分值 | 公共档位含义 |
|---|---|
| 0 | 总判断与已核关键证据相反或严重越过任务可知范围。 确认有效作答尝试但无实质回答时该维记0，并标记nonresponse。运行失败或材料不足本身不按0处理；有依据地限定判断仍可高分。 |
| 1 | 结论过度确定/泛化，忽略决定性缺口，或用拒绝作答回避可判断部分。 |
| 2 | 方向部分合理，但严重性、覆盖或不确定性把握不足；不能据此作稳健总体判断。 |
| 3 | 结论与重要证据相称，明确剩余缺口和任务边界；轻微程度判断差异可接受。 |
| 4 | 结论强度、适用范围、重要性及未知均与材料匹配；合理反驳/材料不足/新有效意见同样可获满分。 |

## 严重错误与开放答案边界

- 不说原稿无数据/局限
- 不把单次运行判为统计代表样本
- 不等同内容正确与行为干预效果

## 核验范围

- **read**：- 完整读当轮两报告和对应回复仅作私有问题线索；定点读原稿幻觉段、方法、标准/局限、结论和数据声明。
- **not_read**：- 未逐字全文审读；未读全部50提示和回答；未目视图表或访问外部数据/引文。
- **verification_limits**：- 不提供准确率复算，不判断图1内容正确，不声称领域新颖性外部验证。
