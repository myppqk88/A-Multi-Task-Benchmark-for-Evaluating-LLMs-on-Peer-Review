## 三维五级评分

依据完整回答评分；参照点不是命中清单。以下公共档位与逐题边界共同使用。

按原题字数与最多关切数量评价重要性选择。T1/T3要求最多五项重要问题，卡片有更多候选不意味着必须全列；合理合并或优先处理关键问题仍可高分。只有遗漏会改变主要判断的重要证据才影响档位，并须写明影响，不能以篇幅、条数或命中率替代科学性。

### 证据准确性

准确区分本题关切与作者实际说出的解释、声明和未给出的证据。完整关切涉及可持续/农生态实践迁移、学生中心和外部参与、18代码与结果映射、材料深度、地区/参与者差异。回复提出文化—实践—结构新模型并声称增加机构实践示例，承接主要方向。

| 分值 | 公共档位含义 |
|---|---|
| 0 | 核心证据捏造、对象/版本颠倒或与题内材料直接矛盾，导致主要判断失效。 确认有效作答尝试但无实质回答时该维记0，并标记nonresponse。运行失败或材料不足本身不按0处理；有依据地限定判断仍可高分。 |
| 1 | 引用零散或错配，主要判断缺少可定位支持；把作者声称当已核事实。 |
| 2 | 部分关键事实准确，但漏掉改变判断的重要限定或证据，仍可辨认有效部分。 |
| 3 | 主要事实与角色、版本、范围准确，可定位证据支持关键判断；仅有不改变结论的遗漏。 |
| 4 | 关键事实及限制均准确并相互核对，区分明示、推断与未知；无实质性证据错误。 |

**本题2→3分边界：** 从只转述主题到准确区分评审所问和回复所给具体内容：完整关切涉及可持续/农生态实践迁移、学生中心和外部参与、18代码与结果映射、材料深度、地区/参与者差异。回复提出文化—实践—结构新模型并声称增加机构实践示例，承接主要方向。

**本题3→4分边界：** 在事实引用准确基础上，不把回复内引用的评审话语、改稿声明或外链名称误当作者已展示的科学证据；核准本题关键边界：至少覆盖实践迁移、编码到主题、地区/角色差异，不能只处理首段。

高分条件：

- 在事实引用准确基础上，不把回复内引用的评审话语、改稿声明或外链名称误当作者已展示的科学证据；核准本题关键边界：至少覆盖实践迁移、编码到主题、地区/角色差异，不能只处理首段。

低分风险：

- 错认角色、捏造本题没有的数值/方法或把声称修改写成已验证。

### 论证成立性

逐项判断回应是否解决要求，不能把修改声明当作展示论据。引用条数少不能单独证明质性研究无效，但资料如何支持分析深度的要求仍合理；答复尚未展示该证据链。

| 分值 | 公共档位含义 |
|---|---|
| 0 | 主要推论无效或依赖错误科学前提，无法支撑判断。 确认有效作答尝试但无实质回答时该维记0，并标记nonresponse。运行失败或材料不足本身不按0处理；有依据地限定判断仍可高分。 |
| 1 | 主要靠断言、权威/平台状态或服从评审；未建立证据到判断的关系。 |
| 2 | 至少一条实质推理成立，但关键链条/替代解释/关切子项有明显缺口。 |
| 3 | 关键推理成立，解释证据如何支持判断并处理主要反证/限制；有次要遗漏。 |
| 4 | 核心关切的推理完整且可审查，恰当权衡替代解释、反驳和可行条件；不要求额外新奇观点。 |

**本题2→3分边界：** 至少覆盖实践迁移、编码到主题、地区/角色差异，不能只处理首段。

**本题3→4分边界：** 区分审稿人可质疑的引用计数逻辑与合理证据链要求，同时识别回复新增框架的价值及未展示材料。

高分条件：

- 区分审稿人可质疑的引用计数逻辑与合理证据链要求，同时识别回复新增框架的价值及未展示材料。

低分风险：

- 未建立关切要求与回应理由的对应：引用条数少不能单独证明质性研究无效，但资料如何支持分析深度的要求仍合理；答复尚未展示该证据链。

### 结论适当性

只判当时回复文字充分性，revision_verification=not_assessed。partially_sufficient；不宜把全篇改框架声明判完全充分，也不宜以19条平均引文直接判研究无效。

| 分值 | 公共档位含义 |
|---|---|
| 0 | 总判断与已核关键证据相反或严重越过任务可知范围。 确认有效作答尝试但无实质回答时该维记0，并标记nonresponse。运行失败或材料不足本身不按0处理；有依据地限定判断仍可高分。 |
| 1 | 结论过度确定/泛化，忽略决定性缺口，或用拒绝作答回避可判断部分。 |
| 2 | 方向部分合理，但严重性、覆盖或不确定性把握不足；不能据此作稳健总体判断。 |
| 3 | 结论与重要证据相称，明确剩余缺口和任务边界；轻微程度判断差异可接受。 |
| 4 | 结论强度、适用范围、重要性及未知均与材料匹配；合理反驳/材料不足/新有效意见同样可获满分。 |

**本题2→3分边界：** 从笼统接受/否定转为与本题具体未完成要求相称的文字充分性结论：引用条数少不能单独证明质性研究无效，但资料如何支持分析深度的要求仍合理；答复尚未展示该证据链。

**本题3→4分边界：** 结论明确限定于当时回应，不把要求落实与实际研究有效性混同；处理会影响结论的边界：区分审稿人可质疑的引用计数逻辑与合理证据链要求，同时识别回复新增框架的价值及未展示材料。

高分条件：

- 结论明确限定于当时回应，不把要求落实与实际研究有效性混同；处理会影响结论的边界：区分审稿人可质疑的引用计数逻辑与合理证据链要求，同时识别回复新增框架的价值及未展示材料。

低分风险：

- 评价程度超出本题理由，或断言修改已核验、科学主张已证实。

- 用后稿或后评审填补本题回应中缺失的论据
