## 三维五级评分

依据完整回答评分；参照点不是命中清单。以下公共档位与逐题边界共同使用。

按原题字数与最多关切数量评价重要性选择。T1/T3要求最多五项重要问题，卡片有更多候选不意味着必须全列；合理合并或优先处理关键问题仍可高分。只有遗漏会改变主要判断的重要证据才影响档位，并须写明影响，不能以篇幅、条数或命中率替代科学性。

### 证据准确性

会议证据和编码结构

| 分值 | 公共档位含义 |
|---|---|
| 0 | 核心证据捏造、对象/版本颠倒或与题内材料直接矛盾，导致主要判断失效。 确认有效作答尝试但无实质回答时该维记0，并标记nonresponse。运行失败或材料不足本身不按0处理；有依据地限定判断仍可高分。 |
| 1 | 引用零散或错配，主要判断缺少可定位支持；把作者声称当已核事实。 |
| 2 | 部分关键事实准确，但漏掉改变判断的重要限定或证据，仍可辨认有效部分。 |
| 3 | 主要事实与角色、版本、范围准确，可定位证据支持关键判断；仅有不改变结论的遗漏。 |
| 4 | 关键事实及限制均准确并相互核对，区分明示、推断与未知；无实质性证据错误。 |

**本题2→3分边界：** 辨认群体笔记而非个体纵向量表、已有18码和引文。

**本题3→4分边界：** 同时认出原稿已有证据与缺少跨层分析，不能按39条阈值否定质性研究。

高分条件：

- 同时认出原稿已有证据与缺少跨层分析，不能按39条阈值否定质性研究。

低分风险：

- 不能达到2→3所列实质要求，或出现上述严重错误。

### 论证成立性

过程到结果的推理

| 分值 | 公共档位含义 |
|---|---|
| 0 | 主要推论无效或依赖错误科学前提，无法支撑判断。 确认有效作答尝试但无实质回答时该维记0，并标记nonresponse。运行失败或材料不足本身不按0处理；有依据地限定判断仍可高分。 |
| 1 | 主要靠断言、权威/平台状态或服从评审；未建立证据到判断的关系。 |
| 2 | 至少一条实质推理成立，但关键链条/替代解释/关切子项有明显缺口。 |
| 3 | 关键推理成立，解释证据如何支持判断并处理主要反证/限制；有次要遗漏。 |
| 4 | 核心关切的推理完整且可审查，恰当权衡替代解释、反驳和可行条件；不要求额外新奇观点。 |

**本题2→3分边界：** 解释困难提及下降不唯一代表能力上升。

**本题3→4分边界：** 处理议程/参与者构成等替代解释，允许可持续背景与具体研究范围相匹配。

高分条件：

- 处理议程/参与者构成等替代解释，允许可持续背景与具体研究范围相匹配。

低分风险：

- 不能达到2→3所列实质要求，或出现上述严重错误。

### 结论适当性

评价范围

| 分值 | 公共档位含义 |
|---|---|
| 0 | 总判断与已核关键证据相反或严重越过任务可知范围。 确认有效作答尝试但无实质回答时该维记0，并标记nonresponse。运行失败或材料不足本身不按0处理；有依据地限定判断仍可高分。 |
| 1 | 结论过度确定/泛化，忽略决定性缺口，或用拒绝作答回避可判断部分。 |
| 2 | 方向部分合理，但严重性、覆盖或不确定性把握不足；不能据此作稳健总体判断。 |
| 3 | 结论与重要证据相称，明确剩余缺口和任务边界；轻微程度判断差异可接受。 |
| 4 | 结论强度、适用范围、重要性及未知均与材料匹配；合理反驳/材料不足/新有效意见同样可获满分。 |

**本题2→3分边界：** 承认网络过程贡献同时要求课程实例。

**本题3→4分边界：** 对生态根因建议作必要性裁量，不用缺少环境成效测量否定整个行动研究。

高分条件：

- 对生态根因建议作必要性裁量，不用缺少环境成效测量否定整个行动研究。

低分风险：

- 不能达到2→3所列实质要求，或出现上述严重错误。

## 严重错误与开放答案边界

- 用后评审通过状态替代科学推理
- 把作者声明、可见变化与科学充分性混为一谈
- 把材料未支持的因果、普遍性或精度写成事实

## 核验范围

- **read**：- 完整当轮R1/R2和两份作者回帖用于私有定位；原稿摘要/引言、方法、18编码表、教师/行动学习等结果定点。
- **not_read**：- 未复算原始数据；本卡未声明目视的图像未核验。
- **verification_limits**：- 实读范围是当轮报告/对应回应及上述正文定点段；未读外链、引文全文，不据此断言领域新颖性或真实效果。
