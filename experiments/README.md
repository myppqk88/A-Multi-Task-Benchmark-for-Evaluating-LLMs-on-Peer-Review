# 实验记录与边界

当前没有运行本版被测模型或自动评审模型，也没有模型排名。这里提供记录格式，不包含自动调用模型的程序。

1. 先下载附件，运行完整校验，记录 commit、Release 与材料清单 SHA256。
2. 锁定开发/正式划分和校准题目。T2 整份报告扩展尚无开发样本，须预留校准论文并从正式比较中排除，或暂不报告该扩展的正式结果。
3. 以题目目录中的 `input.json` 为输入协议，只向模型提供 instruction、题内 input、声明的图片和输出格式；禁止加载评价侧文件、原始完整 PDF 中附带的后续评议、未声明版本或网络资料。图片路径相对该题 input.json 的目录解析。
4. 保留完整输出、原始接口响应（去除密钥和账户信息）、token 用量、失败及重试记录，填写 run_config.template.json。不得为了匹配评分参照反复挑选最佳回答。
5. 缺图、上下文截断、调用失败与无效 JSON 单独记录。若模型不能读图，必须作为不同输入条件报告，不能与完整图文条件直接混评。
6. 团队核验候选卡并校准评分边界，保存独立评分、争议裁决和定稿评分。合理不同意见不能因未命中真人措辞而扣分。
7. 在相同题目/论文覆盖上报告三个维度，按论文处理聚类。评分一致性、效度及增量验证分别解释，不能用一个 κ 值包办。

`responses/`、`ratings/`、`results/` 用于真实实验材料；当前只有目录说明。完整回答保存为 UTF-8 文本或 JSON，评分中 response_excerpt 必须是对应文件内可逐字找到的片段。命令从仓库根目录运行，response_path 建议为仓库相对路径。

API 密钥仅通过环境变量或 Codespaces Secrets 配置，不写进文件或 Git 历史。结果上传前检查接口响应中的账户信息。
